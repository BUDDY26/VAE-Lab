# Variational Autoencoder (VAE) — FashionMNIST

A fully-connected Variational Autoencoder implemented in PyTorch, trained on the FashionMNIST dataset.

---

## Overview

This notebook implements the original VAE formulation from Kingma & Welling (2013).
The model learns a compressed, structured latent space over FashionMNIST images
by maximising the Evidence Lower Bound (ELBO).

---

## Dataset

**FashionMNIST** — 70,000 grayscale images (28×28 px) across 10 fashion categories.
- 60,000 training images, 10,000 test images.
- Pixel values normalised to [0, 1] via `transforms.ToTensor()`.
- Stored locally under `./data/FashionMNIST/`.

> **Note:** An MNIST dataset is also present locally under `./data/MNIST/` (downloaded as a secondary dataset).
> It is **not used** by this notebook. All training and evaluation uses FashionMNIST.

## Architecture

### Encoder

```
Input (784)  →  fc1 (400)  →  ReLU
                              ├── fc21 (20)  →  μ       (mean)
                              └── fc22 (20)  →  log σ²  (log-variance)
```

The encoder outputs two vectors for each input image:

| Symbol | Variable | Meaning |
|--------|----------|---------|
| μ | `mu` | Mean of the approximate posterior q(z\|x) |
| log σ² | `logvar` | Log-variance of q(z\|x) — stored in log form for numerical stability |

`logvar` is the logarithm of the variance (not the standard deviation).
The log transformation keeps the value unconstrained over all reals, which makes optimisation more stable than learning σ² directly.

### Reparameterization Trick

Sampling z ~ q(z|x) = N(μ, σ²) must be differentiable for the encoder to receive gradients.
The reparameterization trick rewrites the sample as:

```
z = μ + σ · ε,    where ε ~ N(0, I)
```

`σ = exp(0.5 · logvar)` is computed from `logvar`.
ε is sampled independently, making z a deterministic function of μ and σ — gradients flow through both.

### Decoder

```
z (20)  →  fc3 (400)  →  ReLU  →  fc4 (784)  →  Sigmoid  →  Output (784)
```

Sigmoid maps decoder outputs to [0, 1], matching the normalised pixel range and making Binary Cross-Entropy a valid reconstruction loss.

## Loss Function — ELBO

The VAE minimises the negative ELBO:

```
Loss = −ELBO = Reconstruction loss (BCE)  +  KL divergence
```

### Reconstruction Term (BCE)

```
BCE = Σ [ x·log(x̂) + (1−x)·log(1−x̂) ]
```

Summed over all pixels and the entire batch (`reduction='sum'`).
Measures how well the decoder recovers the original image from the sampled latent code.

### KL Divergence Term

```
KLD = −0.5 · Σ ( 1 + log σ² − μ² − σ² )
```

Closed-form KL divergence from q(z|x) = N(μ, σ²) to the prior p(z) = N(0, I).
Acts as a regulariser: pushes the approximate posterior toward the unit Gaussian prior,
which enables smooth interpolation and random sampling in latent space.

### Combined Loss and Normalisation

```python
return (BCE + KLD) / x.size(0)   # divide by batch size
```

Both terms are summed over the batch and then divided by `batch_size`.
This normalises the loss to a per-sample scale, making it comparable across runs
with different batch sizes.

## Training Configuration

| Parameter | Value |
|-----------|-------|
| Epochs | 10 |
| Batch size (train) | 128 |
| Batch size (test) | 16 |
| Optimiser | Adam |
| Learning rate | 1e-3 |
| Latent dimension | 20 |

> **No fixed random seed is set.**
> Model weights, reconstructions, and generated samples will differ across runs.
